# auroracafe
A Aurora Café e Bistrô é uma cafeteria e pequeno bistrô nascido em São José dos Campos, SP.
Começou como uma pequena cafeteria familiar e cresceu nos últimos dois anos. Atualmente, atende clientes presencialmente e também recebe pedidos para retirada.

O crescimento trouxe alguns problemas administrativos. Os proprietários utilizam planilhas, anotações em papel e diferentes aplicativos para controlar vendas, estoque e despesas.

A empresa deseja centralizar essas informações em um único sistema.

Esse sistema permite:
— Usuários
* Cadastro de usuários
* Editar usuários
* Ativar ou desativar usuários
* Identifica o tipo de usuário
* Realiza login
* Controla o que cada tipo de usuário pode acessar.

— Produtos

    Nome

    Categoria

    Custo
